# Production audit 371315c5 — repair phase 1
Evidence: 7 seed questions, 3 provisional, 0 qualified; 6 free AI calls; 259 review + 1067 registration backlog items. This release exports all retrieved records as a compact study-centric adjudication packet, including unclassified records; validates human-supplied trial/outcome/competitor fields and prevents repeat report and registry IDs in distinct studies. It does not verify human assertions or grant qualification. See Cochrane Handbook chapters 4, 5 and IV, RevMan study-centric templates, Garner BMJ 2016 doi:10.1136/bmj.i3507. ClinicalTrials.gov v2 pagination and PROSPERO pinned CLI are reused, with bounded same-query recovery (500 x 3 / 50 x 10) rather than treating narrower results as clearance. A partial result remains partial. 
Use: `python scripts/adjudication_packet.py report.json CANDIDATE_ID --output packet.json` then complete submission_template in a separate JSON and run with `--submission submitted.json`. All decisions need actual source locators/quotes and two distinct reviewers; validation is structural, not source adjudication. Explicit manual full-text eligibility, compatible outcome extraction, and competitor decisions are still required.
