# Scientific validation pilot V2

This is a small, manually curated source-linked challenge set, not an independent blinded validation cohort. Reference reports were selected from original PubMed entries and published review results. Test cases: ADMINISTER (39217271; design 38146630; correction 39367252), ADVENT (37634148; related reports 37323994, 41652117, 38864538, 38869507; reviews 42626009, 41651311, 41714974), TRILUMINATE and Tri.Fr (36876753, 39602173; associated reports 39471883, 40159089, 39903153; review 40735794). Links: https://pubmed.ncbi.nlm.nih.gov/ followed by PMID. No PMID is supplied to discovery queries. Record primary retrieval, direct comparison cue retention, known negative and related report retention, and competitor retrieval separately. A completed workflow means the audit executed, not that the method is scientifically validated. Missing reports, false positives and source failures require investigation. No claim about true eligibility, precision, or novelty. The benchmark is intentionally small and not exhaustive. Two independent expert reviewers, a larger diverse test set, and original full texts are needed for a defensible accuracy study.

Do not alter the seven-trial requirement based on retrieval performance. Preserve reports and registry identities, and use exact comparison/family cues only to prioritize deeper verification. The new registry anchor path uses already-retrieved NCT identifiers, not arbitrary registry counts. It is deliberately limited to simple two-arm parallel designs.

Remaining work: completed-job continuation from UI with owner-checked RPC, independently adjudicated trial ledger with outcomes, and a representative held-out validation corpus. No change to cloud qualification from manual ratings.

## Completed-job recovery
The RCT worker publishes a machine-recovery queue (coverage failure, unresolved competitor backlog, or unfinished scoring only when comparison/PICO cues reach the existing floor). Human eligibility cannot be automated by retry. Selection is stored in a worker-only checkpoint and restored; completed source searches and cached judgments are reused by the verifier. Manual-only candidates are not rechecked. The new device-owner RPC uses security invoker, an existing guarded update transition, a 10-minute cooldown and a concurrent matching-job check. It preserves the previous report until worker completion. New insert policy rejects forged completed results. Earlier completed jobs without a worker-authored resume flag are intentionally not eligible. Deployment requires the SQL script to be applied and verified. Sources: https://supabase.com/docs/guides/database/functions ; https://supabase.com/docs/guides/database/postgres/row-level-security . No automatic retry or change in scientific qualification.
