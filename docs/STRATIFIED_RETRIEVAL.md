# Bounded stratified search and registry-reference audit
A live reference pilot found 3/4 competitor reviews after alias/title recovery; no general recall claim. Date-stratified retrieval adds at most 60 records and three logical queries for one strong, truncated seed cell. It preserves existing records and never clears mandatory source coverage. Production registry reverse links are exact PMID result-reference suggestions, not trial merges, because registry links can be wrong or incomplete. EFetch supplies a unique PMCID for the existing OA Methods enrichment. Semantic Scholar gets process-wide pacing and no automatic retry, with the prior per-job circuit breaker intact.
References: Cochrane Handbook ch. 4 and 5; NCBI E-utilities NBK25499; https://doi.org/10.34894/HE6NAQ; https://pubmed.ncbi.nlm.nih.gov/35020887/; https://pubmed.ncbi.nlm.nih.gov/28669351/; Semantic Scholar Graph API documentation.
