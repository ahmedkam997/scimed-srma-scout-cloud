# Mission queue

1. Run live Cardiology and General Surgery discovery on the Phase 3 GitHub
   Actions branch. Record coverage and artifact IDs. Recover partial access
   before interpreting negative results.
2. Triage each retrieved comparison against exact PICO, compatible control
   groups, report-to-trial mapping and verified independent RCT counts. Audit
   at least seven source-linked usable result rows for a common outcome.
3. For surviving candidates, audit recent reviews, their actual cutoffs and
   PROSPERO/OSF coverage. Reconstruct the relevant published comparison for
   update/corrective routes and assess information gain.
4. Produce reviewer-ready, source-linked packets for candidates with credible
   gate coverage. Obtain two independent full-text adjudications and signed
   reconciled approval before asserting first-choice qualification.
5. Integrate technical fixes only where evidence demonstrates a bottleneck.
   Compare PRESS/TARCiS search recovery and published CPU methods on separate
   development controls. Freeze evaluation splits before further training.

## Research Academy

1. Acquire pinned external controls and audit license, identity, label
   coverage and source overlap before use.
2. Build an evidence-linked nomination queue and obtain genuinely
   independent signed judgments before admitting the 30-case temporal test.
3. Compare CPU screening, retrieval and report components in isolation.
   Freeze model options before any held-out score and retain error lessons.
4. Rotate live cardiology and fixed-anchor surgery searches alongside the
   learning workflow. Apply the existing FIRST-CHOICE gates to all leads.
