# Paired evidence-first discovery pilot
Preregistered engineering pilot (not a clinical accuracy study). Same current verifier; ablate evidence-map context and hold other prompt content, candidate cap (4 each), model identity, temperature, token budget, common sample query planner and source limits constant. Freeze the legacy seed context once. Randomize arm order with fixed seed and interleave independent PubMed/Europe PMC validation; identical query strings share results. Primary descriptive endpoint: count of generated proposals with at least the current minimum PICO/design-supported family leads in a complete common source sample, per four requested proposals. Report separately source incompleteness, duplicates, generation shortfall, anchor matches (secondary, circular by construction), review cues, logical model calls, token use when supplied and latency. Do not treat missing data as definitive lack of evidence. Only compute descriptive difference for comparable completed samples with identical actual provider/model and usable evidence map. One candidate per arm undergoes the common deep verifier if both arms are comparable, with equal predeclared ranking, source retrieval cap and eight logical AI calls per arm. No fallback switching; no production job or database mutation. An incomplete deep audit is not a scientific rejection. No claims about eligible trial counts or publication probability. See NIST Using Replicates in Information Retrieval Evaluation https://www.nist.gov/publications/using-replicates-information-retrieval-evaluation and ASReview SAFE https://pmc.ncbi.nlm.nih.gov/articles/PMC10908130/. Real external evaluation needs repeated rotations, randomized order, independently adjudicated blinded PICO/eligibility and novelty reference judgments, held-out cases, and confidence intervals. A single pilot cannot estimate a population-level benefit. Logs/artifact preserve partial results; provider internal retries may exceed logical call counts. Existing free provider configuration is reused, no paid fallback.
