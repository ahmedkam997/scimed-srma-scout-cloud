# Evidence-first pilot v1
The Cardiology pilot samples three rotated Europe PMC searches (30 reports each), groups explicit condition/intervention title co-occurrences with source-indexed design cues, deduplicates reports and reduces registry-linked companion inflation. No extra AI call, paid service or full-corpus download. Local vocabulary is limited; other specialties explicitly fall back to existing seed workflow. Evidence clusters are neither eligible studies nor evidence gaps. Unknown trial IDs do not establish independence, and broad/mixed populations require full-text checks. The model sees cluster citations before other seed cues; deterministic anchor checks mark proposals and provide a bounded ranking priority only. Prior generation history and all scientific gates remain unchanged. The evidence seed checkpoint persists before the AI request and is reused after an interrupted generation. No clinical claims are inferred from a missing cluster.

Sources: Trialstreamer (https://pmc.ncbi.nlm.nih.gov/articles/PMC7727361/), Epistemonikos (https://pmc.ncbi.nlm.nih.gov/articles/PMC7708132/), Campbell guidance (https://doi.org/10.1002/cl2.1125), AHRQ research gap framework (https://www.ncbi.nlm.nih.gov/books/NBK62478/), NCBI API (https://www.ncbi.nlm.nih.gov/books/NBK25497/), Europe PMC API (https://europepmc.org/RestfulWebService). Trialstreamer full installation uses models/RobotReviewer and is not copied into this bounded worker. A smoke workflow measures actual source retrieval and reports cluster count without asserting topic quality. Unit tests exercise deduplication, design/scope, candidate linkage and resume. Compare matched vs exploratory proposals, PICO-supported family leads, qualified decisions and API costs in a subsequent controlled real-job comparison. No external validation or guaranteed improvement.
