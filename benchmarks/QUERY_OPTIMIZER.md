# Clinical query optimizer v1
Production PubMed/Europe PMC discovery retrieval uses a curated, conservative P+I plan: verified MeSH headings plus explicit aliases for recognized concepts, focused title/abstract variant, then legacy P+I/keyword variants within the previous per-source budget. Registry/pipeline and other sources are unchanged. Explicit complex negation/disjunction keeps legacy plans; no automatic exclusion. Broad HF MeSH is not substituted for a defined EF subtype, and named drugs are not substituted by an entire class. Search samples are logged with retrieval counts and metadata quality; positive counts, missing abstracts and zero query hits do not establish eligibility or novelty. No extra AI calls. This is not a validated systematic search. The current curated vocabulary is limited; unknown concepts fall back to focused lexical and legacy retrieval. Sources: Cochrane Handbook ch 4 https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04 ; PubMed Help https://pubmed.ncbi.nlm.nih.gov/help/ ; NLM MeSH Browser D006333 D003324 D009203 D015992 D003078 D000077203 ; Europe PMC API https://europepmc.org/RestfulWebService ; objective strategy development https://pmc.ncbi.nlm.nih.gov/articles/PMC7148214/ ; search tools guide https://ncbi.nlm.nih.gov/books/NBK612662/ .
