# Adaptive free routing (job-local)
Baseline production job 45625247968 reported 24 logical AI requests and 22 legacy failovers. The legacy failover counter includes repeated routing to backup and is not a count of unique provider switches or HTTP attempts. Prior primary 503 and malformed JSON did not establish cooldown. Production now uses a flat job-local adaptive wrapper with preference for last complete JSON route; bounded cooldown (60s transient, 120s throttle, exponential up to 900s except larger explicit Retry-After); disable on confirmed Groq daily exhaustion, credit/configuration failures; no automatic paid route, no health probes, no looping if all routes unavailable. Unknown 403 and policy failures stop rather than bypass. The paired comparison continues using fixed models, and legacy FreeProviderFallback is retained for compatibility. Router metrics distinguish logical calls, provider attempts, extra attempts, actual route changes, transport attempts (includes local HTTP retry; upstream gateway internals unknown) and partial responses. State is process/job-local, not shared across jobs. Valid JSON is not valid scientific content. Existing provider-account tiers are assumed free; Gemini/Groq paid accounts can charge for allowed models, so verify billing settings in account console. Simulation with 24 calls and two permanently unavailable providers verifies 26 attempts rather than 72 for naive repeated three-route retry; not an empirical production speedup.
