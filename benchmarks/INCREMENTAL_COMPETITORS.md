# Incremental competitor assessment
Issue #24 historical audit: 13/27 candidates had unassessed reviews, 11/27 unassessed registrations. Existing cap was total selected records per pass. Revised cap counts uncached work, retains valid resolved assessments and selects unattempted records ahead of failed attempts. Resolved cache now binds PICO, record identity, evidence and a version; older record-only cache entries deliberately require reassessment. A changed question or evidence invalidates reuse. No change to qualification gates or automatic non-overlap inference. Unresolved entries and out-of-budget citations still block. Existing source-level deduplication is unchanged in this patch; cross-database identifier alias improvements require separate validation. No new API service. Reference: Cochrane chapter 4 https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04 ; ASReview SAFE https://pubmed.ncbi.nlm.nih.gov/38429798/ ; deduplication evaluation https://pubmed.ncbi.nlm.nih.gov/36241035/ . Synthetic regression tests measure logical calls, queue progress, stale cache and failed-record starvation. This does not guarantee that the production recovery pass will exhaust every queue or that more ideas will qualify.
