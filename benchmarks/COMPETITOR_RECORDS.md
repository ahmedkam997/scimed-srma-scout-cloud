# Competitor citation identity and enrichment v1
Adapted principles from ASySD (https://pubmed.ncbi.nlm.nih.gov/37674179/), Deduplicator (https://pubmed.ncbi.nlm.nih.gov/39095913/), SRA-DM (https://pubmed.ncbi.nlm.nih.gov/25588387/) and comparative evaluation (https://pubmed.ncbi.nlm.nih.gov/42306873/). Not a port or validated implementation. Exact DOI/PMID connected components for published reviews; refuse all merges in conflicting components; titles alone do not establish identity, separate registrations and articles. Retain raw ledger rows and audit source variants. Use the longest actual abstract representative. Europe PMC core API (https://europepmc.org/RestfulWebService), at most two targeted enrichment queries per production assessment pass, only for selected reviews without useful abstracts. Exact identifier verification, conflicting identifiers or distinct retrieved texts remain unresolved, preserve source provenance. No extra AI requests, no changes to scientific gates. Existing ledger uses source_record_id within evidence type; historical overwrites are not recoverable by this patch. A separate storage migration and versioned external validation are needed to fully address source-ID collisions and dedup accuracy. Synthetic tests are not population-level accuracy estimates.
