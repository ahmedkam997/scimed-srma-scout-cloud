# Self-diagnostics and bounded remediation v1
2026-11-25: run 45622888183 retrieved 11 clusters but both generation requests returned HTTP 503. This is an upstream dependency failure; no comparison was established. The paired retry probes at most three configured fixed free endpoints before either arm, chooses one healthy endpoint and never switches during evaluation. Up to 21 logical AI requests including probes, not counting bounded provider-internal retries. It reuses the exact original seed snapshot when available; provenance and fallback are recorded. Diagnostic rules classify dependency, quota, configuration, database timeout, incomplete evaluation and scientific pending states. Worker logs emit a sanitized category, comparison emits a JSON artifact. No additional database write privileges, arbitrary shell commands, code patch generation, auto-merge, automatic changes to scientific gates, or endless retry. New code fixes should first reproduce failure, pass regression tests on a separate branch, receive human review and only then merge.
