# PICO signal v1
Methodological basis: Cochrane Handbook chapters 3 and 4 (https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04), Trialstreamer (https://pubmed.ncbi.nlm.nih.gov/32940710/), and ASReview validation (https://pubmed.ncbi.nlm.nih.gov/42106619/). These do not validate our heuristic. The cloud and CLI enforce a conservative feasibility gate on P+I+compatible design signals, with the existing minimum of four family-level leads. Unknown comparator/outcome does not exclude, and no output is an included study. The library constructor retains its legacy default for existing programmatic consumers/tests; specify require_pico_signals=True for production. All records retained; report shows up to 40 prioritized rows with counts for the full corpus. No new API requests or model calls. The limited synonym list, lexical thresholds, unsupported design types, missing abstracts, and group ambiguity are limitations. Next: externally labeled holdout, recall/precision and abstention by design and specialty; improve vocabulary using controlled terminology without automatic exclusion. A prior checkpoint lacking this gate cannot silently restore a qualified decision.

Source-linked regression examples: EMPEROR-Preserved (PMID 34449189) and EMPEROR-Reduced (PMID 32865377). Limited directional synonym expansion includes four SGLT2 inhibitors; the class term alone does not establish a named drug match. These examples are development fixtures, not blinded external validation.
